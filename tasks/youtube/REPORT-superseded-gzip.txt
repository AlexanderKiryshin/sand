КОНФИГУРАЦИЯ SDK
Mirra 5.1.31 закреплён на 9c5c97b57a117874bc5f23e3f9c420cbced1ef30.
Build configuration — встроенный FallbackConfiguration: офлайн-провайдеры без браузерной
автоинициализации. Editor configuration — прежний EditorConfiguration.
Платформенными сохранениями, языком, жизненным циклом и рекламой владеют игровые адаптеры
YoutubePlatform / SandYouTube. Это исключает двойную инициализацию SDK и двойные ready-сигналы.
Встроенный Mirra YouTube preset использует другой JS-контракт и упаковщик с ZIP/CDN;
в этом порте он не выбран. Registry Mirra генерируется при сборке пакета и не обнаруживает
конфигурации из Assembly-CSharp, поэтому используется существующий офлайн-пресет.
WebGL define: YOUTUBE_PLAYABLES. Шаблон: PROJECT:SandYoutube.

ПОДТВЕРЖДЁННЫЕ ПРОВЕРКИ
- Editor C# и отдельная player-компиляция без UNITY_EDITOR; успешный WebGL linking и экспорт.
- 17 детерминированных JS-регрессий: bridge-results.txt, bridge.test.cjs.
- 18 проверок настоящего WebGL player в Edge с программным WebGL2 и подменённым только
  SDK YouTube: browser-results.json, browser-smoke.cjs. Тестовый SDK отсутствует в ZIP.
- Загрузка, единственные ready-сигналы, начальный облачный баланс, остановка/возврат
  рендеринга, unmute при паузе, размеры окон, сохранение материального изменения и reload.
- Магазин: false/rejection не награждают и освобождают кнопку; true даёт ровно 100 монет;
  результат рекламы во время platform pause ждёт resume; rewardId стабилен.
- Console: 0 ошибок; Network: только локальные файлы и запрос SDK YouTube.
- Проверены содержимое ZIP, имена файлов, относительные ссылки, размеры и отсутствие
  необработанных Unity template-маркеров. git diff --check пройден.
- Скриншоты: desktop.png, portrait.png, portrait-touch.png, landscape.png, square.png,
  shop.png, shop-after-ad.png. В узком viewport используется letterbox вместо обрезания.
- Потребление JS heap и время локального запуска записаны в browser-results.json;
  это точечное измерение, не сертификация пикового потребления памяти на мобильных устройствах.
- После WebGL build изменена только CSS-геометрия viewport; тот же HTML исправлен в
  исходном шаблоне и экспортированном player и повторно проверен в браузере.

на реальных устройствах. Локальные размеры архива не заменяют этот замер.

ПОВТОРЕНИЕ
В Unity: выбрать WebGL, Window > Sand > Build > YouTube Playables.
Из batchmode: Unity.exe -batchmode -nographics -quit -projectPath <project>
  -buildTarget WebGL -executeMethod YoutubeBuild.Build -logFile <log>
SAND_YOUTUBE_OUTPUT задаёт новый, ещё не существующий каталог экспорта.
JS: node tasks/youtube/bridge.test.cjs
Browser (нужен Playwright + Edge): node tasks/youtube/browser-smoke.cjs <export-directory>
ZIP: python tasks/youtube/package-release.py <export-directory> <new-zip-path>
