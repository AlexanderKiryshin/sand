Исправлены пропуски обновления локализации и применение сохранённого фона.

Причины:

- Галерея не подписывалась на смену языка; увеличенный просмотр фона не обновлял свои заголовок и кнопку закрытия.
- Подсказка активного обучения бустерам и окно покупки набора во время ожидания не обновляли перевод.
- Уведомление о нехватке монет содержало английскую строку вместо ключа локализации.
- Поле создавалось до готовности SDK/облачного сохранения. После загрузки выбранный индекс уже читался правильно, но Canvas продолжал использовать предыдущие mesh и текстуру.

Проверки:

- `pwsh -NoProfile -File Tools/check_theme_restore.ps1`: до исправления FAIL, после PASS. Проверяет производственный обработчик обновления фона; отрисовка заменена заглушкой. Неизменившийся фон не пересобирается каждый кадр; выбор из сохранения не меняет явный предпросмотр.
- `python Tools/check_ui_language_theme.py`: 15 PASS в отдельной Unity 6000.3.4f1-копии `Library/EditorCrashValidation`. Использует настоящий UI, производственные обработчики и изолированный профиль. Результаты исходного и исправленного кода: `before.txt`, `after.txt`.
- Управляемый код успешно скомпилирован компилятором Unity 2022.3.62f3 для Editor и Player с актуальными исходниками. Логи: `Temp/UiLanguageThemeChecks/ManagedCompile/editor.log`, `player.log`.
- `git diff --check`: PASS для изменённых файлов задачи.

Полная WebGL/IL2CPP-сборка и проверка в браузере не выполнялись.

Дополнительная существующая проверка `Tools/check_cosmetic_analytics.ps1` не дошла до выполнения тестов: её заглушки не содержат `YoutubePlatform`, который уже используется в `ThemeCatalog`. Этот старый тест в рамках задачи не изменялся.
