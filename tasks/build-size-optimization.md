Оптимизация размера Android-сборки, 10 сентября 2026.

**APK уменьшился с 30,42 до 18,50 МиБ: −11,92 МиБ (−39,19%).**

Исходный файл: [2.apk](/E:/myProjects/sand/2.apk), 31 900 195 байт. Новая релизная сборка: [sand-optimized.apk](/E:/myProjects/sand/Builds/sand-optimized.apk), 19 398 015 байт. В обоих APK одна архитектура — armeabi-v7a. Сравниваются сохранённый APK и текущий проект; отдельный вклад каждого переключателя не измерялся.

В основной проект перенесены следующие изменения:

- Удалены пять неиспользуемых PNG из Resources: старые Magnet, Transparent и Shuffle, временный дубликат Magnet и Cofffe. Проверено отсутствие ссылок по GUID; загрузка этих ресурсов в Unity возвращает null. Обращения через старый BusesUiArt теперь используют общий атлас.
- Атлас BoosterAtlas импортируется в 512×512, с Android-форматом ETC2_RGBA8. Каждая иконка имеет разрешение 256×256. Размер атласа в отчёте сборки уменьшился с примерно 6 МиБ до 262 292 байт. Исходный PNG сохранён для будущего изменения разрешения.
- Для Android включены Managed Stripping Level = Medium и IL2CPP Code Generation = OptimizeSize. Настройки сохранены в ProjectSettings; повторное применение доступно через Window → Sand → Build → Apply Size Optimizations.
- Сохраняется ранее выполненная миграция уровней в компактный текстовый формат: превью создаются из данных уровня при открытии галереи, освобождаются при смене страницы и не требуют PNG в сборке.

По отчёту Unity текстуры до сжатия пакета занимают 7,8 МБ вместо 18,6 МБ, все пользовательские ресурсы — 10,4 МБ вместо 22,2 МБ. Потоковые ресурсы и звук также меньше в новой сборке; таблица показывает фактические изменения APK без приписывания всей разницы только одному шагу.

Проверки выполнены в отдельной копии проекта Unity 6000.3.4f1. IL2CPP и Gradle завершились успешно. В проверке данных все 445 уровней совпали с оригиналами, превью 300 уровней совпали с исходными PNG пиксель в пиксель; прошли проверки кодека и сериализации. В Play Mode прошли загрузка сцены, показ атласа и старые обращения к нему, магазин, включение магнита, галерея и освобождение её текстур, настройки, запись/чтение временного профиля и перезапуск уровня. Снимки игры, магазина и галереи проверены визуально.

Производительность, реклама, покупки и сохранения после перезапуска Android-приложения этой проверкой не подтверждены.
