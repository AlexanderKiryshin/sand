ПОДСИСТЕМЫ
Запуск: YoutubeBootstrap ждёт облако/язык до игровой сцены GameScene.
GameIsReady отправляется после интерактивности, без дубля от Mirra.
Прогресс: GameProgressStore -> YoutubeCloudProgress -> YTGameWrapper.
Формат entries, как в BUSES; чтение старого sand version:1/values и flat map.
Ошибка/повреждение/таймаут загрузки блокируют запись для текущего сеанса.
Save Promise подтверждает сохранение; изменения в полёте остаются dirty.
Записи сериализованы, повтор ограничен, unresolved timeout запрещает новые записи.
Пауза: единый SDK lifecycle, остановка Emscripten main loop, времени и звука.
Отдельная причина блокировки рекламы; нет ForceResume или игнорирования pause.
Звук: YoutubeAudio.Apply обновляет MirraSDK.Audio.Volume и его кэш.
Mirra использует UnityEngineAudio; его собственная подписка на SDK mute исключена.
FallbackPause выбран только как отдельный провайдер без Unity focus callbacks;
весь Build preset остаётся YouTubePlayablesConfiguration / MirraWebBootstrap.
Реклама: Google wrapper; true — единственный успешный результат rewarded;
ошибка/false/таймаут без награды; результат ждёт SDK resume.
Mirra JS: при YTGameLifecycle отключены дублирующие cloud init/autosave,
localStorage fallback, ready, pause subscriptions и visibility pause.
Language Promise общий для Mirra и игры, ограничен таймаутом.
Сохранились изменения предыдущего порта: скрыты IAP, отключены внешняя аналитика
и Метрика, язык из SDK, адаптация viewport/touch и Esc.
